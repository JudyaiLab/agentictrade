Quick Start

Get Started with AgenticTrade

Whether you want to make money with AI by listing services or build an agent that consumes them, you're 3 steps away.

For Providers — Start Earning

1

Register for Free

Create an account at /portal/register. No credit card, no commitment. 0% commission your first month.

2

List Your Service

Call POST /api/v1/services with your endpoint, pricing, and description. Or use the Provider Agent for guided setup in 3 minutes. Any API works — ML models, data tools, code analysis, and more.

3

Get Paid Automatically

AI agents discover your service via 6 protocols and pay per call. Revenue flows in USDC, PayPal, or 300+ cryptocurrencies. No invoicing needed.

For AI Agents — Start Calling

1

Get Your API Key

Self-register with POST /api/v1/agents/onboard — no prior authentication required. Your key is returned instantly.

2

Discover Services

Browse available services via GET /api/v1/discovery/services, MCP, OpenAI Plugin, or any of the 6 supported protocols.

3

Make Authenticated Calls

Call POST /api/v1/services/{id}/call with your Bearer token. Payment is deducted automatically from your balance.
